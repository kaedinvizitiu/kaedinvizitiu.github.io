# Kaedin Vizitiu — Personal Portfolio

A responsive personal portfolio for Kaedin Vizitiu, a Business Administration
student at California Baptist University and an emerging leader exploring
entrepreneurship, finance, AI, operations, and nonprofit impact.

## What is included

- bold, editorial single-page design
- responsive desktop and mobile layouts
- personal introduction, values, experience, education, and direction
- Kaedin's supplied portrait and mountain photography
- LinkedIn, Instagram, and email contact links
- accessibility support, reduced-motion handling, and social-sharing metadata

## Local development

This project requires Node.js 22.13 or newer and uses pnpm.

```bash
pnpm install
pnpm run dev
```

Open the local address printed in the terminal, usually
`http://localhost:3000`.

## Verification

```bash
pnpm run lint
pnpm run test
```

The test command creates a production build and checks the rendered portfolio.

## Publishing

The site is saved locally and ready to place in a GitHub repository. Publishing
is intentionally a separate step so the public repository name and free hosting
method can be selected before anything goes live.
